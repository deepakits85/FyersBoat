# Simple 11:15 rule — ONLY this

1. Refs = **10:45** + **11:15**
2. Agar **10:45** ki trade usi index pe abhi running hai → **11:15 skip**
3. First BO = 3m **CLOSE** > ref High
4. Retracement **> 50%**
5. Second BO = entry **on touch** (no close wait)
6. **SL = ref Low** (short: ref High), **Target = 1:3**
7. Nifty + Bank + Sensex

**Kuch aur nahi:** no trail, prior, filters, gap, maxSL/day, freshness, 90m wait, square-off.
